# Security Policy

This repository is itself security-sensitive. Please avoid publishing unpatched vulnerabilities, real credentials, or exploit payloads containing third-party secrets in public issues.

## Reporting a vulnerability

Prefer GitHub private vulnerability reporting / a private security advisory for this repository when available.

Include:

- affected commit/version;
- impact and threat model;
- minimal reproduction;
- whether the issue crosses a claimed security boundary;
- suggested mitigation if known.

## Scope note

Until runtime enforcement is explicitly implemented and documented in a later phase, this project should not be represented as protecting production agents. Phase 0 is schema/domain foundation work only.
