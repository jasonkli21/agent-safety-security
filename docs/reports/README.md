# Implementation and Review Reports

Reports are produced after implementation/review sessions and should describe what actually happened rather than restating the plan.

Each completed phase should have an implementation report using the required structure in that
phase's plan. Review and correction passes should have a separate report that records the baseline,
changes, verification, deviations, remaining limitations, and next-phase readiness.

- `phase-0-implementation-report.md` — original Phase 0 implementation record.
- `phase-0-review-fixes-report.md` — post-review corrective changes to Phase 0.
